# Lynn guided scenarios

The first guided scenario is the versioned fixture at
`city-packs/us-ma-lynn/fixtures/downtown-housing-a.json`. It demonstrates 200 apartments and the
four first-order modules. Values are engineering placeholders until the Lynn data audit and model
calibration are complete.

Future guided examples should be plausible teaching cases, not representations of live proposals,
unless the source, date, and public context are documented.
