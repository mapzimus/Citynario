# Contributing to Citynario

Thank you for contributing. Civic decision-support software earns trust through clarity, careful
validation, and honest limits.

1. Open an issue describing the user need, affected city pack or module, and expected evidence.
2. Keep pull requests focused and add tests for changed behavior.
3. Document new assumptions, datasets, licenses, formulas, and uncertainty.
4. Run the Python and TypeScript checks listed in `AGENTS.md`.
5. Never upload protected student records, personal data, API keys, or data without redistribution
   rights.

Model changes should include a worked example and a citation to the method or source. City Pack
changes should update `sources.yaml` and increment the pack version when published.
