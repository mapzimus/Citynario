# Governance

Citynario currently uses a maintainer-led model. Major changes to domain contracts, public model
outputs, City Pack verification, privacy posture, or licensing require a documented decision and
proportionate review.

Public output changes require a version change, model-card update, release note, and golden-scenario
review. Verified City Packs must name a maintainer and correction path. Governance should evolve
only when contributors and local partners create a real need for broader roles.
